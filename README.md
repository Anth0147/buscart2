# Sistema de Automatización Movistar

## 📋 Requisitos del Sistema

### 1. Versión de Python
- **Python 3.10** o superior (Recomendado **Python 3.12**).

### 2. Módulos Requeridos
- `playwright >= 1.40.0`
- `ddddocr >= 1.6.0`
- `requests >= 2.28.0`
- `Pillow >= 9.0.0`
- `urllib3 >= 1.26.0`

## ⚙️ Instalación

1. Instalar los paquetes/módulos requeridos:
   ```bash
   pip install -r requirements.txt
   ```

2. Instalar los binarios del navegador para Playwright:
   ```bash
   playwright install chromium
   ```

## 🚀 Instrucciones de Ejecución

Para iniciar el sistema principal y acceder al menú interactivo:

```bash
python ejecutar.py
```
